Flicker

A Windows survival game written in C. Collect candles to keep the room lit and survive until 6 AM.

Download the latest release (Windows 64-bit)

How to play
Download Flicker.zip and extract all files.
Run Flicker.exe.

If Windows reports that VCRUNTIME140.dll is missing, install the Visual C++ Redistributable (x64).

Goal: Pick up candles to keep the room bright, avoid enemies and survive until 6 AM.

Controls: WASD, arrow keys and Shift

Features
Tutorial, level select and endless mode
Zombie, ghost and gargoyle enemies
Basic in-game Level Creator for Level 5: left click to place, right click to remove, then save
Saved high score

Built with
